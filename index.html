☁️ Hướng Dẫn Đưa Web Lên Mạng & Đồng Bộ Đa Thiết Bị

Hoàn toàn miễn phí — Chạy mượt trên cả Điện thoại & Máy tính

🔑 Cách lấy và nhập mã API Google AI Studio (chỉ nhập 1 lần trên mỗi máy):

  1. Truy cập aistudio.google.com/apikey và đăng nhập bằng tài khoản Google.
  2. Nhấn nút "Create API key" → sao chép chuỗi mã khóa (bắt đầu bằng AIzaSy...).
  3. Mở nút ✨ Quét ảnh AI ngay trên ứng dụng, dán mã vào ô Google AI Studio API Key rồi bấm 💾 Lưu.

🔒 An toàn khi đưa web lên mạng: Mã API Key chỉ được lưu cục bộ trong localStorage trên chính trình duyệt của bạn, hoàn toàn không nằm trong mã nguồn index.html — bạn có thể thoải mái đưa web lên GitHub Pages hay Netlify mà không lo lộ Key.

🚀 Cách 1: Netlify Drop (Nhanh nhất — 30 giây, không cần Git)

  1. Tạo một thư mục mới tên thoigianbieu và đặt file index.html vào trong.
  2. Vào trang app.netlify.com/drop (đăng nhập miễn phí).
  3. Kéo thả cả thư mục đó vào ô trống trên màn hình → nhận ngay đường link HTTPS (VD: https://lichcuaban.netlify.app).

🐙 Cách 2: GitHub Pages (Ổn định vĩnh viễn)

  1. Tạo Repository mới trên github.com (VD: chronoplan).
  2. Nhấn Add file → Upload files và tải file index.html lên.
  3. Vào Settings → Pages → Branch: main → Save. Sau 1 phút web sẽ chạy tại https://ten-ban.github.io/chronoplan/.
📱 Mẹo cài lên màn hình chính điện thoại như App thật: Mở link web trên Safari (iPhone) → bấm nút Chia sẻ (↑) → Thêm vào MH chính; hoặc Chrome (Android) → Menu 3 chấm → Cài đặt ứng dụng.

📦 Cách A: Đồng bộ thủ công siêu nhanh (Có sẵn ngay trong app)

Nhấn nút 💾 Sao lưu → Xuất file (.json) trên máy tính, gửi qua Zalo/Drive rồi nhấn Nhập file (.json) trên điện thoại. Không cần tạo tài khoản đám mây.

⚡ Cách B: Đồng bộ Thời gian thực Tự động (Firebase Firestore Miễn phí)

  1. Vào console.firebase.google.com → tạo Project miễn phí → bật Cloud Firestore và Authentication.
  2. Vào Project Settings → Your apps → Web (</>) để lấy đối tượng firebaseConfig.
  3. Bật Offline Persistence của Firestore để app vẫn chạy Offline-First mượt mà, và khi có Wi-Fi/4G sẽ tự động đồng bộ giữa Điện thoại & Máy tính trong 1 giây!
<script type="module">
import { initializeApp } from "https://www.gstatic.com/firebasejs/11.6.1/firebase-app.js";
import { getFirestore, doc, setDoc, onSnapshot, enableIndexedDbPersistence }
  from "https://www.gstatic.com/firebasejs/11.6.1/firebase-firestore.js";

const firebaseConfig = { apiKey: "...", projectId: "...", appId: "..." };
const app = initializeApp(firebaseConfig);
const db = getFirestore(app);
enableIndexedDbPersistence(db).catch(() => {});

const syncRef = doc(db, "schedules", "MA_DONG_BO_CA_NHAN_CUA_BAN");
onSnapshot(syncRef, (snap) => {
  if (snap.exists()) {
    localStorage.setItem("chronoplan_offline_v1", JSON.stringify(snap.data()));
    location.reload();
  }
});
</script>
